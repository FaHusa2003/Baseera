
# بصيرة (Baseera)

نموذج يكتشف جدول القيم الغذائية في صور الملصقات العربية، تمهيدًا لقراءة السكر وحجم الحصة.

## الأدوات

YOLOv8s (Ultralytics) · Google Colab · Roboflow

## الملفات

- `best.pt`: النموذج المدرّب.
- `notebook.ipynb`: دفتر التدريب والاختبار.
- `test_images/`: صور الاختبار.

## طريقة التشغيل

1. افتح الدفتر في Google Colab.
2. ارفع `best.pt` وصورة جدول غذائي.
3. شغّل خلية التنبؤ لعرض الجدول المكتشف.
