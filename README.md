# بصيرة (Baseera AI)

نموذج أولي يعتمد على الرؤية الحاسوبية واستخراج النصوص ثنائي اللغة (العربية والإنجليزية) لتحديد جداول القيم الغذائية في صور المنتجات المغلفة، واستخراج السعرات الحرارية والسكريات والبروتينات وعرض تنبيهات وملاحظات توضيحية عبر واجهة تفاعلية.

## التقنيات والأدوات المستخدمة
* **اكتشاف الجدول:** YOLOv8 (Ultralytics) · Roboflow · Google Colab
* **معالجة الصور واستخراج النصوص:** OpenCV (CLAHE) · Tesseract OCR (`ara+eng`)
* **منطق المعالجة والواجهة:** Python · Regular Expressions (Regex) · Gradio

## هيكلية الملفات الرئيسية
* **النموذج المدرّب:** `best (2).pt` (أو `best.pt`) لتحديد منطقة جدول القيم الغذائية
* **دفتر التدريب والاختبار:** `Copy of train-yolov8-object-detection-on-custom-dataset.ipynb`
* **بيانات الاختبار:** `test_images/`

## خطوات التشغيل
1. فتح دفتر العمل في **Google Colab** وربط **Google Drive** لضمان حفظ الملفات والأوزان.
2. التحقق من توفر ملف النموذج المدرّب (`best (2).pt`) وتجهيز أو رفع صورة جدول القيم الغذائية.
3. تشغيل خلايا الكشف والمعالجة واستخراج القيم وتشغيل واجهة **Gradio** لعرض الجدول المكتشف والقيم المستخرجة والتنبيهات.
